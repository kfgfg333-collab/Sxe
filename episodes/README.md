# Серии

Новая серия: скопировать `episode_template/` → `EPNN_slug/` (например `EP01_novgorod_1240`), заполнить файлы 00–10 по порядку.
Изображения серии (костюм, локации, удачные кадры) — в `EPNN_slug/refs/`.
