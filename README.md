# Вера: путешественница во времени — производственная система

Папка проекта для Claude Code: канон сериала, проверенные гайды по Google Flow / ElevenLabs / CapCut, шаблон пакета серии и проектные skills. База знаний — обычные Markdown-файлы, которые Claude Code читает в каждой сессии (через `CLAUDE.md`); в модель ничего «навсегда» не загружено.

## Запуск
1. Распаковать папку `Vera-Time-Travel` и открыть её в Claude Code.
2. Разрешать веб-поиск и правку файлов по запросу. Платные действия, установки и изменения аккаунтов не подтверждать без проверки — система их не требует.
3. Написать команду (см. ниже).

## Команды
| Команда | Результат |
|---|---|
| `История 1` | Claude выбирает сильную тему и делает полный пакет |
| `История 2` | Следующая новая тема по журналу `episodes/README.md` |
| `История: Ледовое побоище` | Полный пакет по вашей теме |
| `Сделай серию про [событие], длительность 60–90 секунд. Используй канон проекта и выдай полный пакет.` | То же |
| `Улучши историю` | Правки хука, драматургии, фактов, удержания текущей серии |
| `Проверь серию` | Финальная проверка (`/final-qc`) |
Скиллы можно вызывать и напрямую: `/episode-production`, `/historical-research`, `/flow-prompt-review`, `/continuity-check`, `/final-qc`.

## Структура
```
CLAUDE.md                     постоянные инструкции и правила
PROJECT_BOOTSTRAP_PROMPT.md   исходный промпт проекта
references/                   референсы Веры (лицо, тело, листы персонажа)
knowledge/                    канон, гайды сервисов, протоколы, источники
episodes/README.md            журнал выпусков и банк идей
episodes/episode_template/    шаблон пакета серии 00–10 (+ refs/)
.claude/skills/               проектные skills
```

## Рабочий цикл серии
Пакет от Claude → **костюмный референс** (Nano Banana во Flow/Gemini с лицом и телом Веры) → клипы Flow (Ingredients, 9:16) → озвучка ElevenLabs → субтитры и монтаж CapCut → `Проверь серию` → публикация → через 48 ч/7 дней — данные удержания в `08_publish_pack.md`.

## Что сделать вам один раз
1. Во Flow создать проект сериала и загрузить ассеты: `references/vera_face_reference.png` → имя `vera_face`, `references/vera_body_reference.png` → `vera_body`. Для ingredients используйте вырезанные лицо/тело, а не целые листы персонажа.
2. В ElevenLabs выбрать голос Веры по процедуре из `knowledge/elevenlabs_guide.md` §3 и вписать VOICE_ID и настройки в паспорт голоса.
3. Проверить в интерфейсах пункты из разделов «Не подтверждено» гайдов (9:16 в меню, русский в автосубтитрах CapCut, знак ударения в ElevenLabs) — и сообщить Claude результат, чтобы он обновил гайды.

## Важно
- Claude не имеет доступа к вашим аккаунтам Flow, ElevenLabs, CapCut: он готовит тексты и указывает, что и куда загрузить.
- По официальному списку Google (на 25.10.2026) Flow доступен 18+ и **Россия в списке стран не значится**; учитывайте это при работе с сервисом.
- Возможности сервисов меняются: даты проверок и ссылки — в `knowledge/sources.md`; Claude перепроверяет гайды, если им больше 60 дней.
