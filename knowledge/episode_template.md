# Производственный пакет серии

Рабочие файлы-шаблоны лежат в `episodes/episode_template/`. Для новой серии: скопировать папку в `episodes/EPNN_slug/` (например `EP01_novgorod_1240`), заполнить по порядку, добавить строку в журнал `episodes/README.md`.

| Файл | Раздел | Ключевое содержимое |
|---|---|---|
| 00_brief.md | A | Заголовок, место/дата, идея, эмоция, главный вопрос, каркас хук→развязка |
| 01_research_and_factcheck.md | A | Факты по классификации ✅⚖️🎭⚠️👁, быт эпохи, источники с датами |
| 02_vera_costume_reference_prompt.md | B | Исследование костюма; промпт полного роста; промпт портрета |
| 03_script_and_voiceover.md | C, F | Сценарий, слова/длительность, чистый текст ElevenLabs, указания по подаче и произношению |
| 04_flow_clips.md | D | 8–12 клипов: 10 пунктов на клип, готовый промпт + запасной |
| 05_cover_prompt.md | E | Промпт обложки 9:16 без текста, 2–4 заголовка |
| 06_subtitles.md | G | Титры с примерными таймкодами |
| 07_capcut_edit_plan.md | G | Монтаж по секундам, звук, музыка (лицензии), цвет, экспорт |
| 08_publish_pack.md | H | Заголовок, описание, хэштеги, закреплённый вопрос; аналитика после публикации |
| 09_continuity.md | 9 | Паспорт непрерывности |
| 10_final_qc.md | 12 | Финальный чек-лист — отмечать только реально проверенное |

## Выдача в чат
После заполнения файлов — в чат: краткая сводка (тема, длительность, число клипов, спорные моменты) + костюмный промпт и первые 2 клипа в копируемых блоках; остальное — в файлах. Если пользователь просит «всё в чат» — выдать всё.
