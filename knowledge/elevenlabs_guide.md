# ElevenLabs — голос Веры

**Дата проверки: 25.10.2026.** Источники — `knowledge/sources.md` (раздел ElevenLabs).

## 1. Подтверждено официальной документацией
| Что | Факт |
|---|---|
| Рекомендуемая модель | **Eleven v4** (`eleven_v4`, анонс 28.09.2026): ElevenLabs называет её улучшением v3 почти во всём; 90+ языков, русский поддерживается |
| Лимит символов v4 | Страница моделей: 10 000; блог-анонс: 5 000 — **расхождение**; серия ≈ 1 000–1 300 символов, лимит не критичен |
| Другие модели | Eleven v3 (70+ языков, 5 000 симв.), Multilingual v2 (29 языков, 10 000 симв., лучше читает числа), Flash v2.5 (быстрая, числа без нормализации) |
| Паузы | v4 и v3 **не поддерживают** SSML `<break>`. Паузы — многоточия, тире, разбивка на абзацы, аудиотеги |
| Аудиотеги (v4, применимы к v3) | В квадратных скобках: `[laughs]`, `[whispers]`, `[sighs]`, `[exhales]`, `[sarcastic]`, `[curious]`, `[excited]`, `[crying]`, `[snorts]`, `[mischievously]` и др. Лучше работают теги, описывающие подачу голоса |
| Произношение v4 | IPA между косыми чертами прямо в тексте: `/ˈslovo/`; результат зависит от голоса — тестировать |
| Phoneme-теги | Только `eleven_flash_v2` |
| Alias / словари | Alias-правила и фонетическое переписывание; словари произношения (.PLS/.TXT) в Studio, Dubbing и API; регистрозависимы, срабатывает первое правило |
| Скорость | 0.7–1.2, по умолчанию 1.0; крайние значения снижают качество |
| Числа | Нормализация включена по умолчанию; надёжнее писать числа словами |
| Несколько голосов | Разным персонажам — разные голоса из Voice Library, реплики помечать именами (Text to Dialogue) |
| SynthID | ElevenLabs объявила о внедрении SynthID для части контента (Google I/O 2026) |

## 2. Не подтверждено — проверить в интерфейсе
- Диапазоны и названия Stability / Similarity / Style для v4 (у v3 были пресеты Creative / Natural / Robust — проверить, сохранились ли).
- Работает ли знак ударения (комбинируемый акут, «за́мок») в русском тексте v4 — протестировать на 3–5 трудных словах.
- Поддержка IPA для русских слов конкретным голосом.

## 3. Паспорт голоса Веры (постоянный)
| Параметр | Значение |
|---|---|
| Голос | Женский, 25–30 лет, тёплый, с лёгкой хрипотцой, средне-низкий регистр; нативный русский без акцента |
| Подача | Живая, уверенная, разговорная; лёгкая игривая ирония; не дикторская и не театральная |
| Темп | 135–145 слов/мин, speed 1.0 (допуск 0.95–1.05) |
| Артикуляция | Чёткие окончания, без «съеденных» слогов |
| Эмоциональный диапазон | от шёпота-удивления до сдержанной тревоги; пики — 1–2 за серию |
| Модель | Eleven v4 |
| Выбранный голос | `VOICE_ID: ________` (заполнить после выбора; записать сюда название и настройки) |
| Настройки | `Stability: ___ · Similarity: ___ · Style: ___ · Speed: 1.0` (зафиксировать после теста) |

**Выбор голоса (один раз):** Voice Library → фильтр Russian, Female, Young/Middle → 3–5 кандидатов → прочитать тест-абзац ниже → выбрать → записать ID и настройки в таблицу. Альтернатива — Voice Design по описанию из таблицы. Голос больше не меняем.

Тест-абзац:
```
Так, стоп. Я точно в Новгороде? Пахнет дёгтем, рыбой и мокрым деревом… И, кажется, на меня только что очень внимательно посмотрел человек с топором. Ладно. Улыбаемся.
```

## 4. Правила текста озвучки
- Только произносимый текст: никаких ремарок камеры, таймкодов, скобок-комментариев (кроме аудиотегов).
- Числа и даты словами: «в тысяча двести сороковом году».
- Аудиотегов — не больше 3–5 на серию; только там, где нужна смена подачи.
- Паузы: «…» — короткая пауза-раздумье; « — » — смена мысли; новый абзац — пауза ~0.5–1 с.
- Трудные имена: сначала обычное написание; если ошибается — фонетическое переписывание (писать как слышится: «Всеволод» → «Фсеволот» обычно не нужно, но для редких имён и топонимов — да), знак ударения (тест, см. выше) или IPA в `/…/` (v4); итог фиксировать в `09_continuity.md` → «Произношение».
- Длинный текст: генерировать целиком (контекст интонации), при сбоях — по абзацам с одинаковыми настройками.
- Длительность: ориентир 125–150 слов/мин; **после генерации измерить реальную длину** и записать в `03_script_and_voiceover.md`.

## 5. Безопасность
Не выполнять генерации/покупки от имени пользователя. API-ключи не хранить в репозитории.
